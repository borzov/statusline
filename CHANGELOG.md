# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-04-25

Internal refactor focused on rendering speed and code clarity. No user-visible behavior changes — output is byte-identical for typical inputs.

### Changed

- **Performance: ~30% faster on warm cache** (`0.29–0.37s` → `0.19–0.26s`). Achieved by consolidating `jq` invocations: 27 references in the hot path reduced to 11.
- A single `jq` pass now extracts all input JSON fields up front into a bash array (was ~10 separate invocations of `echo "$input" | jq`).
- `get_subscription_info` reads `subscriptionType` and `rateLimitTier` in one tab-separated `jq` (was two).
- `build_rl_segment` reads from a pre-extracted `native_rl_json` and uses one `jq` per data source instead of five — three rate-limit segments now produce 6 subprocesses instead of 15.
- `extra_usage` block uses a single tab-separated `jq` (was four).
- `cwd`-fallback uses an explicit `if/then/fi` instead of `||`/`&&` shorthand to avoid bash precedence pitfalls.
- Rate-limit segments are built via a `for` loop over a list of `label:key:window` entries instead of three duplicated blocks.
- `printf "%s" "$var"` for ANSI color variables — no format-string vulnerability surface.

### Removed

- Dead branch in `build_rl_segment` pct fallback condition (`pct=0 && native_exists=""` is unreachable — those imply each other).
- Duplicate `mkdir -p /tmp/claude` calls — hoisted to a single `CACHE_DIR` setup at the top.
- `grep | tail` for tier multiplier extraction — replaced with bash `BASH_REMATCH`.

### Internal

- `local_cmd` (used outside any function) renamed to `installed_cmd` in `install.sh` so it doesn't read like a misplaced `local` keyword.
- Stays compatible with macOS system bash 3.2 — no `mapfile`, no `${var,,}`.

## [0.1.0] - 2026-04-25

Initial public release.

### Added

- Two-line layout: model, context tokens, cwd/worktree, git branch with change counts, session duration, subscription tier or API cost, effort level — all on line 1; rate-limit progress bars (five-hour, weekly, weekly-sonnet) on line 2.
- Optional third line for `extra_usage` credits when enabled on the account.
- Color thresholds at 50%/70%/90% (green → orange → yellow → red) for percentages and bars.
- macOS Keychain integration for OAuth credentials, with `~/.claude/.credentials.json` fallback for Linux.
- Hybrid rate-limit data: native percentages from Claude Code input JSON, `resets_at` from the OAuth usage API, with API fallback when native data is missing.
- Subscription cache (60s) and OAuth usage cache (60s) under `/tmp/claude/` to keep render time below 200ms with warm caches.
- Single-call OAuth blob reading per render — `security find-generic-password` runs once instead of twice.
- Numeric input validation for token counts and context window size to prevent arithmetic errors on malformed input.
- 3-second timeout on the OAuth usage API request, so a stalled network never freezes the bar.
- `install.sh` supporting `--copy`, `--no-config`, and `--uninstall` modes.
- Three reproducible README screenshots generated by `docs/scripts/screenshot.sh` via [`freeze`](https://github.com/charmbracelet/freeze).
